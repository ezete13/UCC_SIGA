# Índice de Recursos para el Agente (SIGA)

Este directorio (`agent/`) contiene todos los recursos, documentación, directrices y plantillas que un Agente de IA necesita para trabajar en el proyecto SIGA.

## 📂 Estructura de Directorios

- [README.md](./README.md): Reglas de operación, prohibiciones y checklist para la IA.
- [CONTEXT.md](./CONTEXT.md): Resumen ejecutivo del sistema, arquitectura y stack técnico.
- [TASKS.md](./TASKS.md): Backlog de tareas actuales, roadmap y estado del proyecto.
- [docs/](./docs/): Documentación profunda generada en la Fase 3.
  - `00-overview.md` - Visión general.
  - `01-glossary.md` - Glosario de términos.
  - `02-user-stories.md` - Historias de usuario iniciales.
  - `03-architecture.md` - Clean Architecture y diagramas.
  - `04-decisions.md` - ADRs (Architecture Decision Records).
  - `05-conventions.md` - Convenciones de código y arquitectura.
  - `06-roadmap.md` - Hoja de ruta completa.
  - `07-conflicts.md` - Conflictos resueltos.
- [templates/](./templates/): Plantillas para artefactos estándar (ADRs, Historias de Usuario, Issues).
- [prompts/](./prompts/): Prompts reutilizables para diferentes tareas (Refactor, Tests, Review).
- [.editorconfig](./.editorconfig): Reglas de formato de código base para el agente y el IDE.
- [.env.example](./.env.example): Ejemplo de variables de entorno (sin secretos reales).
